# Handoff: статус Jolt-интеграции на 2026-07-22 (после §22.11: живой регресс-фикс + other-vehicles mirroring)

Снимок состояния для передачи работы. Читать `docs/jolt-integration-techanalysis.md`
§22.6-22.12 (самые свежие), не эту сводку, за деталями/кодом/цифрами.

## Что сделано в этой сессии (по порядку)

1. **Реализован и живьём проверен `ExportStaticObstaclesToJolt`** (§22.9) - box/sphere/trimesh
   статика экспортируется в Jolt (2357/2577 body-less геомов на тестовом уровне). По дороге
   найдены и исправлены два реальных бага: `dSpaceGetGeom` - dead-стаб (обход через
   `dxSpace::m_firstEnabled`/`m_firstDisabled`+`dxGeom::next` вместо), и не всегда единичный
   кватернион из `dGeomGetQuaternion` (`.Normalized()` защитно).
2. **Пользователь сообщил живой регресс** (§22.10): "игра стала медленнее загружаться... игра
   остаётся в главном меню", уточнено - "в главном меню ездит одна машина по карте, это реальная
   симуляция, но это не загруженный сейв". Два разных бага под одним симптомом:
   - **Баг A (исправлен)**: `StepPhysics` перезапускал ПОЛНЫЙ экспорт (2357 тел, ~1600 trimesh)
     на каждом из 30 кадров задержки вместо одного раза - ~30-кратный лишний костыль. Теперь
     экспорт строго один раз; подтверждено <0.5с суммарно.
   - **Баг B (исправлен через откат конфига)**: `[jolt_harness] apply=1` (выставлен в конце
     предыдущей сессии "готово к тесту") заставлял Jolt реально вести машину, помеченную как
     "машина игрока" - включая, судя по всему, фоновую демо-машину главного меню. С новыми 2357
     статическими препятствиями она могла физически застрять о одно из них. Откачено на
     `apply=0` (безопасный дефолт, проверенный весь сеанс).
3. **По запросу пользователя ("do other vehicles") реализовано zеркалирование чужих машин**
   (§22.11, `source/fix/joltshadow.cpp`, `MirrorOtherVehicles`) - каждая машина, которая не
   является ни игроком, ни уже полностью Jolt-ведомой AI-целью, получает простое kinematic
   box-тело в Jolt (размер из `protoInfo->m_massSize`, позиция/поворот - `GetPosition()`/
   `GetRotation()` каждый кадр через `MoveKinematic`), чтобы Jolt-ведомая машина с ней
   сталкивалась вместо прохождения насквозь. Перечисление - тот же примитив, что уже использует
   Stage 3 (`CServer::Instance()->m_pObjects` + `cast<Vehicle>()`), свежий скан каждый кадр (не
   кэшируется - безопасно относительно уничтоженных машин, та же осторожность что и в UAF-фиксе
   §22.2). Собрано и живьём проверено чисто (apply=0, 0 ошибок) - **но не проверено с реально
   несколькими машинами одновременно** (демо-сцена главного меню - вероятно только одна машина).

## Текущее состояние деплоя (`F:\HTA_Kraken`)

- `hta.exe` **не запущен**.
- `kraken.dll` - актуальная сборка ветки `jolt`, включает §22.9-22.11 целиком.
- `data/kraken.ini` - **`[jolt] enabled=1`**, **`[jolt_harness] apply=0 player_only=1 ai_count=0
  shadow=1`** - БЕЗОПАСНЫЙ дефолт (диагностика без реального вождения). **Пользователь должен сам
  включить `apply=1` ПОСЛЕ входа в свой сейв**, не сидя в главном меню - иначе Jolt возьмёт под
  контроль не ту машину (§22.10). Тюн-значения подвески/трения сохранены (`susp_frequency=1.80
  susp_damping=0.60 friction_long=0.93 friction_lat=1.00`). **Важно**: ini-парсер учитывает
  только первое вхождение секции - проверять `grep -n "^\[jolt\]"` при сомнении.

## Известные, честно неполные места (не баг, осознанный scope)

1. **Capsule (58 экземпляров на тестовом уровне)** - не экспортируется в статике (нужен доворот
   локальной оси Z→Y).
2. **Вложенные под-спейсы** (154+ `dxSimpleSpace`/иные, class 11-14) - статический экспорт не
   рекурсирует в них, размер пробела не измерен.
3. **Несколько одновременных Jolt-ведомых машин** (`player_only=0`, `ai_count>0`) - other-vehicles
   зеркалирование корректно их исключает из зеркал, но архитектурное решение "что делать с
   несколькими Jolt-ведомыми машинами одновременно" не принято.
4. **Живое подтверждение обоих фиксов + новой фичи пользователем** - НЕ проверено визуально:
   (a) главное меню больше не виснет, (b) машина не проходит сквозь box/sphere/trimesh-статику,
   (c) Jolt-ведомая машина не проходит сквозь другие машины. Всё это ждёт теста пользователем
   в загруженном сейве с `apply=1`.
